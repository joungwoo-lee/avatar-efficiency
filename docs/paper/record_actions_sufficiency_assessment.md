## 부족한 것 (논문에서 "미래 과제"로 명시한 항목)

1. **사람 실측 정답 0건** — 절대 배율을 검증할 근거가 없음. 논문은 배율을 "구간·상대 비교"로만 제시.
2. **단일 사용자·단일 PC 모집단** — 57세션 전부 한 사람의 기록. 일반화 불가. 논문은 "예비 연구(pilot)"로 표기.
3. **작업 종류 분포 미기재** — 어떤 세션이 코드/문서/조사였는지 분류 통계가 없음. 논문은 쓰기 단어 구성비(코드 44 / 문서 31.5 / 데이터 24.4%)만 인용.
4. **산출물 품질 항 부재** — 분자는 "결말에 살아남은 산출물"을 세지만 그 산출물이 맞는지(테스트 통과 여부 등)는 배율에 안 들어감. 기존 v0.1 논문의 q(s) 항과 결합 필요.
5. **결정론 판정 규칙의 재현 검증 부재** — DEEP/SKIM/WASTE 분류가 사람의 실제 읽기와 맞는지 표본 검사가 없음.
6. **시간 흐름에 따른 수치 불일치** — §3.3 표(63세션, 2.54배)와 §7 표(57세션, 4.63배)가 다른 코드 버전 기준. 논문은 §7 최신값을 본문에, §3.3 은 think 도입 효과 이력으로만 인용.

## 논문에서 택한 포지셔닝

- 제목·초록에 "deterministic", "LLM-free", "pilot" 명시.
- 핵심 기여 = (a) 결말 기여 기반 휴먼화 원리, (b) 분모의 타임스탬프 실측 전환, (c) 요율 근거 3단계 공개 + 민감도 병기 = **감사 가능한 측정기**.
- 배율 수치는 보고하되 "이 PC 57세션에서" 로 한정, 한계 절에 12항목 전부 이관.
