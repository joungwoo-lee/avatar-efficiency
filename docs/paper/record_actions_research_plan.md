# record_actions 논문 — 좋은 연구·밸류맥싱 측정법이 되기 위한 계획 (2026-08-29)

## 진단
1. 사람 실측 정답 0건 → 4.63배는 모델 의견.
2. 단일 사용자·단일 PC.
3. "얼마나 빨랐나"만 잼. 밸류맥싱엔 "어디서 낭비되고 뭘 바꾸면 더 버나"가 필요 — 성적표지 조향 장치 아님.

## 1단계 — 정답 만들기 (4~6주)
- 측정 세션 20~30개 층화 표본(소/대 × 코드/문서/조사).
- 개발자 3~5명, 같은 과제 AI 없이 수행·시간 실측. 가능하면 교차설계(같은 사람 AI 유/무).
- 실측으로 요율 재피팅. seed 5개(verify·correct·review·think·skim) 오차 공개. "모델 vs 실측" 한 줄.
- DEEP/SKIM/WASTE 눈가림 라벨링 2명 → κ 보고.

## 2단계 — 품질 항
- 세션 결과 라벨(테스트 통과·머지·되돌림·폐기) → 속도 × 품질.
- 되돌려진 세션의 사후 수리 시간을 분모에 얹어 "AI 가 만든 뒷일" 계상 (METR −19% 설명 항).

## 3단계 — 조향 장치 (밸류맥싱 본체)
- 세션별 낭비 프로필: WASTE 읽기·번복 왕복·재실행 왕복·interrupt.
- 낭비 프로필 ↔ 배율 회귀. 지시 방식/과제 유형별 낭비 배수.
- 개입 실험(지시 구체화 / 서브에이전트 / 테스트 우선) 전후 배율 변화 — 측정이 행동을 바꿔 가치를 올린 증거.
- 조직 레벨: paper.md 아바타·비용 회계와 결합, 업무별 이득/손해 표.

## 4단계 — 재현성·외부 타당성
- ≥5명·≥3대 기계, 과제 분포 공개, 익명 코퍼스+코드 공개.
- 수치 표를 코드 버전에 고정.
- 기준선 비교: LLM 심판 vs 결정론 측정기, 정답 대비 정확도 — "왜 LLM 없이"의 답.

## 목표 주장
"결정론 측정기는 사람 실측 대비 중앙 ±X% 안(1) · 품질 보정 배율 Y배(2) · 낭비 프로필 개입으로 배율 +Z%(3)."

우선순위: 1단계가 뿌리. 이것만으로 "제안"→"검증된 도구".
